# Welcome to 180 Documentation

We are pleased to introduce the centralized **180workspace Platform & Architecture Documentation Portal**.

This portal unifies all engineering specifications, system blueprints, database schema catalogs, REST API contracts, and developer onboarding runbooks across our enterprise ecosystem.

## Key Highlights of this Release

1. **Unified Architecture Blueprint:** Comprehensive documentation detailing the Modular Monolith pattern, Next.js 15 SSR client, Express API Gateway, and PostgreSQL namespace resolution.
2. **Dynamic Multitenancy Isolation:** In-depth breakdown of our `company-db` connection switching middleware and zero-leakage security model.
3. **Real-Time WebSockets & Queueing:** Detailed Socket.IO namespace contracts and Redis/BullMQ asynchronous processing workflows.
4. **Developer Runbooks:** Step-by-step local development setup, environment blueprints, and Git PR conventions for contributors.
