# Design Patterns & Architecture

This document outlines the high-level design patterns and architectural decisions used across the 180workspace Platform.

## Backend Patterns (Express)
- Controller-Service-Repository Pattern
- Singleton Pattern (Database Connections)
- Middleware Pattern (Auth, Logging, Rate Limiting)

## Frontend Patterns (Next.js)
- 3-Layer Architecture (UI, Behavior, Service)
- Higher-Order Components (HOCs) for Auth
- Custom Hooks for state and data fetching
